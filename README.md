# REM-Calculator
REM Calculator - A C++ console calculator with 9 operations (+, -, ×, ÷, !, ^, %, log, radical). Features: error handling, custom precision, and smooth user experience.

## Why did I start this project?
**As a personal project, being started to practice what I had learned, spending two weeks on it taught me so much about:**
- Designing simple UX
- Considering wrong inputs from users
- Working with libraries such as `<windows.h>`, which taught me how to use `Sleep()` and more.

## Key Features
- ✅ **Smart Error Handling** – Division by zero, negative factorials, invalid roots, and log bases are all handled gracefully.
- ✅ **Custom Precision** – Set decimal places for division, logarithm, and radical results.
- ✅ **Animated Interface** – Eye-catching startup screen with calculator design, using arrays and loops.
- ✅ **Input Validation** – Won't crash on invalid inputs.

## Technologies Used
- **Language**: C++17
- **Libraries**: `<iostream>`, `<cmath>`, `<iomanip>`, `<string>`, `<windows.h>`
- **Key Functions**: `Sleep()`, `system("cls")`, and mathematical functions
- **Platform**: Windows

## How to Run
**Using any C++ compiler, preferred to run on Windows (due to the `<windows.h>` dependency).**
